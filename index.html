AI Usage Policy

                    
Only template documents may be processed through this tool. Documents containing real customer PII — including names, Social Security numbers, account numbers, or mailing addresses — will be automatically detected and blocked.

                    
This policy is enforced by Newcourse Communications AI Usage Policy V1.0. Questions should be directed to your supervisor or IT.

                

                

                    
How It Works

                    
Upload a Word (.docx) or PDF template document. The formatter extracts the document structure and uses AI to generate NcFormatter-compatible HTML, preserving conditional logic, field tags, and layout.

                    
After generation, use the Need changes? panel to describe adjustments in plain language. Click Reset to revert to the original AI output at any time.

                

                

                    
Advanced Mode & Layout Images

                    
Enabling Advanced before uploading sends the model a first-page layout snapshot for improved table and column accuracy.

                    
    
                        
  • PDF uploads — rasterized automatically on the server.
    • 
                        
  • Word uploads — requires a print-accurate PDF conversion. Set the GOTENBERG_URL environment variable to a running Gotenberg instance, or upload a PDF exported directly from Word.
